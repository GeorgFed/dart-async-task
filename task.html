Тесты — запасной сценарий

Основной путь — реальные запросы к CoinGecko без токена. Если API недоступен, требует ключ или ограничивает запросы, проверьте решение тестами с HTTP-моками.

Интернет нужен для SDK, пакетов и живого запуска. После установки тесты работают без сети. Недоступность API не снижает балл; обработка ошибки обязательна.

Две модели, всего шесть полей

fromJson только извлекает значения. Отдельный валидатор схемы писать не нужно.

Создайте реализацию CoinRepository

Создайте свой класс с implements CoinRepository и верните его из createRepository(client). Название класса свободное. Используйте переданный HTTP-клиент: в тестах он заменяется моком. Запросы, JSON и обработку ошибок реализуйте самостоятельно. Базовый URL: https://api.coingecko.com/api/v3/.

getTopCoins(limit)

Верните List<Coin>. GET coins/markets: USD, сортировка по капитализации, per_page=limit, page=1. Вне 1–250 — ArgumentError до запроса.

getCoinDetails(id)

Верните CoinDetails. GET coins/{id} с localization=false. Неожиданный верхний тип JSON в обоих методах — понятное исключение.

getCoinsStream(ids)

Загружайте детали последовательно через async* и yield. Порядок совпадает с ids. Первая ошибка завершает поток; следующие запросы не выполняются.

pollPrices(ids, interval)

Запрашивайте coins/markets с vs_currency=usd, ids через запятую и per_page=250. Первый запрос сразу, затем пауза после ответа. Поддерживаем до 250 id.

getGrowingCoinNames(ids)

Преобразуйте getCoinsStream: where оставляет только положительный процент, map извлекает имя. Порядок и ошибки сохраняются.

close()

Закройте переданный HTTP-клиент. В main все методы вывода уже включены через runDemo; close вызывается в finally. Вывод переписывать не нужно.

Поллинг без сюрпризов

запрос→событие→пауза→новый запрос
  • Первый запрос — после подписки, без начальной паузы.
  • interval отсчитывается после ответа; запросы не перекрываются.
  • interval ≤ 0 → ArgumentError. Пустой список id → завершение без HTTP.
  • Ошибка завершает polling. take(2) ограничивает его двумя обновлениями.
  • После отмены нет новых запросов. Уже начатый запрос или пауза могут завершиться позже.

Что легко перепутать

  • price_change_percentage_24h — проценты. price_change_24h — изменение в деньгах.
  • Цена списка лежит в current_price, процент деталей — внутри market_data.
  • Описание — объект языков: нужна строка description.en.
  • Для фильтра роста null, ноль и отрицательные значения пропускаются.
  • Stream деталей отправляет каждый результат по готовности; пустой список завершается сразу.

Ошибки — часть решения

Проверяйте HTTP status до декодирования JSON: сообщение должно содержать код ошибки. Ограничьте ожидание ответа 15 секундами. Обрабатывайте отсутствие соединения, таймаут, повреждённый JSON и неожиданный верхний тип ответа.

Не заменяйте ошибку пустым списком или фиктивным успехом. Передавайте понятное исключение вызывающему коду — main уже выводит ошибку. Подойдут стандартные Exception, FormatException или TimeoutException; свой класс исключения не требуется. Полная валидация каждого поля не нужна.

0

Основная загрузка не реализована или решение не удаётся объяснить.

1

Работают модели, запросы и Stream. Обработаны HTTP-ошибки, сеть, таймаут и неверный JSON. Проходят группы «Модели», «Запросы», «Stream»; вы объясняете await/yield.

2

Также работают поллинг и where/map. Ошибки потоков останавливают дальнейшие запросы, клиент закрывается. Проходят 32 теста и CLI; вы объясняете порядок и отмену. Если API доступен — покажите живой запуск, иначе CLI на моках.

Сдайте код, вывод проверок и короткое объяснение. Новую рубрику объявляют до начала работы.

Дополнительные задания

dart run lib/main.dart — реальные запросы. Между двумя обновлениями цен пауза 30 секунд. Возможны HTTP 429 и недоступность сети. Поддержку токена добавлять не нужно: при недоступном API используйте тесты.

Опционально, без дополнительных баллов: альтернативный репозиторий на Dio с мок-тестами; json_serializable и build_runner для этих же шести полей. Обязательный starter содержит только два Dart-файла; кодген дополнительно создаст .g.dart.
